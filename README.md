# Mauk Tenieb

Transmedia underground worldbuilder.

**Korhogo** is a self-proliferating sci-fi world and an uncanny crucible-platform for: Experimental Hip-Hop, Concept Albums, Illbient, IDM, and Experimental Dub. Its 18 avatars: the **Korhogo Fauna**, aka the Masks (Honey Buzzard/Marumero, Aube/Rosy Fingers, Plague of Justinian, Truce/↑héé↑è↑e, Malika/Quintina, Naphta-Kerema, Cadaver Synod, Croisière Noire, Grand Colonel, Poisoned Well, Unkle Maukie, Hátra Lövés, Maiden Call, C7H5N3O6, Silent Pact, Auvergne, Ts'ui Pên, dogXim).

Also: Braindance, Ethnotronica, Free Improvisation, Concept Soundtracks.

## Tools

Built for Insert Koin and the works above. The licence is in each repository.

- [Detour](https://github.com/MaukTenieb/detour): cuts portrait sheets into sprite strips and places the eye lights
- [FaunaTor](https://github.com/MaukTenieb/faunator): reads web and .onion pages through Tor clients that run in the page
- [KorhoTube](https://github.com/MaukTenieb/korhotube): lists the public videos of a YouTube channel as JSON
- [Korhoname](https://github.com/MaukTenieb/Korhoname): tells whether a name is free on Discogs, MusicBrainz, in trademark registers and in Wikidata, read the way the public reads it
- [Reporhogo](https://github.com/MaukTenieb/reporhogo): searches forty-one code forges for a topic and lists the repositories it finds
- [Photofauna](https://github.com/MaukTenieb/Photofauna): a photo editor with 44 looks, part of Insert Koin
- [TorView](https://github.com/MaukTenieb/torview): a desktop browser in Go that routes its traffic through the official Tor daemon
